## 5. 接口设计

### 5.1 接口规范

- 基础路径：`/api/v1`
- 认证方式：Bearer Token
- 数据格式：JSON

### 5.2 接口列表

#### 5.2.1 [接口名称]

**请求信息：**
```
POST /api/v1/[resource]
Content-Type: application/json
Authorization: Bearer {token}
```

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| [param1] | string | 是 | [说明] |
| [param2] | int | 否 | [说明] |

**请求示例：**
```json
{
    "param1": "value1",
    "param2": 123
}
```

**响应示例：**
```json
{
    "code": 200,
    "message": "success",
    "data": {
        "id": 1,
        "param1": "value1"
    }
}
```

**错误码：**

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 400 | 参数错误 | 检查请求参数 |
| 401 | 未认证 | 重新登录获取token |
| 403 | 无权限 | 联系管理员 |
| 500 | 服务器错误 | 联系技术支持 |
